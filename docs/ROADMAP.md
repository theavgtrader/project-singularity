# Development Roadmap

The scope is intentionally staged. The first objective is a stable, attractive, testable vertical slice—not a large unfinished map.

## Milestone 0.1 — Foundation and Undercity prototype

**Current milestone**

- [x] Create Godot project configuration.
- [x] Add a low-spec 2D main scene.
- [x] Add keyboard movement.
- [x] Add a prototype Undercity street.
- [x] Add simple character and terminal interactions.
- [x] Add provisional HUD and rain effect.
- [x] Document story, art, architecture, licensing, and roadmap.
- [ ] Open and run on the creator's PC.
- [ ] Fix any local import or runtime errors.
- [ ] Review the visual direction on the target display.

## Milestone 0.2 — Art pipeline and first district

- Select a small number of compatible, properly licensed pixel-art packs.
- Record each source and licence before importing.
- Establish character, environment, UI, and effects standards.
- Replace placeholder building and character shapes selectively.
- Create a small connected Undercity area with one interior.
- Add collisions and deliberate navigation boundaries.
- Add basic camera polish and accessibility settings.

## Milestone 0.3 — Core action loop

- Basic melee or ranged attack.
- One enemy type with readable telegraphs and damage feedback.
- Health, damage, defeat, and recovery.
- One technology protocol ability.
- A compact test encounter.
- Initial sound effects.

## Milestone 0.4 — RPG foundations

- Character attributes and progression data.
- Inventory and equipment slots.
- Item definitions and pickup interactions.
- Dialogue and quest data structures.
- Local save/load with versioned data.
- Initial vendor or service interaction.

## Milestone 0.5 — First narrative slice

- Introduce the protagonist and the father's legacy without explaining the full mystery.
- Add a small quest chain.
- Introduce one human faction and one AI-related encounter.
- Build one research or transit interior.
- Deliver a complete short chapter ending.

## Milestone 0.6 — Polish and release candidate

- Consistent art, animation, UI, and audio.
- Performance profiling on the reference PC.
- Input remapping and readable UI.
- Save integrity and recovery testing.
- Exported Windows build.
- Clean README, credits, licences, screenshots, and itch.io page.

## Release discipline

Do not start a new district until the current one is playable and stable. Do not add multiplayer, a massive open world, voice acting, online services, or complex 3D effects to the initial scope.
