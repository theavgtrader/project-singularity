# Assets

This folder will contain imported assets that are approved for use in Project: Singularity.

Planned folders:
- characters/
- environments/
- effects/
- audio/
- fonts/

Before adding a third-party pack:
1. Verify the original creator and download page.
2. Read the exact licence for the specific pack.
3. Add the source and licence details to docs/ASSET_REGISTER.md.
4. Preserve attribution and licence files where required.
5. Check that the art matches the game's perspective, scale, and palette.

The first prototype uses in-engine placeholder geometry and therefore has no external asset dependencies.
